Sort the dump

With memory switched on, the agent kept everything that looked worth keeping. Each line below is one of those things, or close to one. Pick where each one really belongs, then press Reveal answers at the end.

The words, once you have sorted

Short-term
The conversation the agent is in. It lasts as long as the conversation, and the window keeps only the last few turns of it.
Working
True for this run only: a yes to one action, the step the agent is on.
Episodic
What happened, one event at a time. Its home is the trace, read when someone asks.
Semantic
What is true, whatever run you are in. Authored facts live in the brand files; learned ones go to the memory store.
Procedural
How the work gets done. Written down as a skill, loaded when the job needs it, not retrieved.
Long-term
Anything that outlives the conversation: episodic, semantic and procedural are all long-term. Only one of them is the memory store.

Two more words are ways of managing one long conversation, not kinds of memory: sliding window (keep the last N turns) and compaction (shorten the conversation, e.g. with a summary).
