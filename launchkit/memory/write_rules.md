# What to keep in memory

Keep only what changes how you work next time and is still true after this conversation ends.

Keep it only if it is one of these four kinds. Put the kind first in its topics.

- **preference**: how this marketer or brand likes things done.
  Example: "Maya wants headlines as three options to pick from, not one."
- **domain fact**: something true about the brand, its products or its market that no brand file says yet.
  Example: "Harbor's shop window screens are portrait, so window posters are made tall."
- **workflow**: the order or the way the work gets done.
  Example: "Maya reviews the square feed format first."
- **correction**: something you got wrong that the marketer put right, so you do not get it wrong again.
  Example: "When Maya says 'the banner', she means the web size, not the display one."

## Never keep

- Thanks and small talk.
- A yes or no to one action. That permission is for one run.
- The work itself: headlines, posters, pictures, sizes. It lives on the board.
- A rule already in the brand files.
- One choice on one afternoon, like "make this one wide".

When unsure, do not keep it.
