# Decisions

One line each, in your own words. The room compares them after the build.

## 1. Should the agent write and run code at all, or should LaunchKit get one tool per calculation? What does each cost?

## 2. Where should the agent's code run, and what does your answer cost? One sandbox per run, per conversation, or per brand?

## 3. Which limits does a run need, and what number did you pick for each? Which would you lower first with forty brands on one machine?

## 4. A message arrives while a job runs: wait, refuse, or stop the job? Who owns the job once the page is gone?

## 5. After a restart, what does "carries on" mean, and which steps must never happen twice? When would you take a durable-execution engine instead?

## 6. Why the scripted models: what does the room lose by not watching the real model make these four mistakes, and what does it gain?
